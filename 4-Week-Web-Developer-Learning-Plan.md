# 4-Week Web Developer Learning Plan

## Overview
This intensive 4-week program will take you from beginner to job-ready web developer, covering HTML, CSS, JavaScript, and modern web development practices. Each week builds upon the previous, with daily tasks designed to maximize learning through hands-on practice.

---

## Week 1: HTML & CSS Foundations

### Weekly Goal
Master HTML structure and CSS styling fundamentals. Build 3 static web pages from scratch.

### Daily Breakdown

#### Day 1: HTML Basics
- **Tasks:**
  - Learn HTML document structure (DOCTYPE, html, head, body)
  - Practice semantic HTML tags (header, nav, main, section, article, footer)
  - Create a personal bio page with headings, paragraphs, lists, and links
  - Understand attributes and their usage
- **Mini Project:** Build a basic personal portfolio landing page (HTML only)

#### Day 2: HTML Forms & Media
- **Tasks:**
  - Learn form elements (input, textarea, select, button)
  - Practice embedding images, videos, and audio
  - Understand form validation attributes
  - Create a contact form page
- **Mini Project:** Build a survey/feedback form with various input types

#### Day 3: CSS Fundamentals
- **Tasks:**
  - Learn CSS syntax, selectors (class, id, element, descendant)
  - Practice colors, typography, and text styling
  - Understand the box model (margin, padding, border)
  - Style your Day 1 portfolio page
- **Mini Project:** Add comprehensive styling to your portfolio

#### Day 4: CSS Layout Basics
- **Tasks:**
  - Learn display properties (block, inline, inline-block)
  - Practice positioning (static, relative, absolute, fixed)
  - Understand float and clear
  - Create multi-column layouts
- **Mini Project:** Build a blog post layout with sidebar

#### Day 5: Flexbox
- **Tasks:**
  - Master flex container properties (justify-content, align-items, flex-direction)
  - Practice flex item properties (flex-grow, flex-shrink, flex-basis)
  - Create navigation bars and card layouts
  - Build responsive components
- **Mini Project:** Create a responsive navigation bar and gallery layout

#### Day 6: CSS Grid
- **Tasks:**
  - Learn grid container and item properties
  - Practice grid-template-columns, grid-template-rows
  - Understand grid-gap, grid-area
  - Create complex layouts
- **Mini Project:** Build a complete dashboard layout using CSS Grid

#### Day 7: Week 1 Project
- **Tasks:**
  - Combine all Week 1 skills
  - Build a fully responsive multi-page website (3-5 pages)
  - Include: Homepage, About, Portfolio/Gallery, Contact form
  - Use semantic HTML, Flexbox, and Grid
- **Deliverable:** Complete static website hosted on GitHub Pages

### Week 1 Best Resources
1. **MDN Web Docs - HTML & CSS** (https://developer.mozilla.org/en-US/docs/Learn)
   - Comprehensive, authoritative documentation with interactive examples
   - Perfect for reference and deep understanding

2. **freeCodeCamp - Responsive Web Design Certification** (https://www.freecodecamp.org/learn/2022/responsive-web-design/)
   - Hands-on interactive coding challenges
   - Project-based learning approach

3. **CSS-Tricks Complete Guide to Flexbox & Grid** (https://css-tricks.com/snippets/css/complete-guide-grid/)
   - Visual guides with examples
   - Excellent for understanding layout systems

## Week 2: JavaScript Fundamentals

### Weekly Goal
Learn JavaScript basics, DOM manipulation, and event handling. Build 3 interactive web applications.

### Daily Breakdown

#### Day 8: JavaScript Basics I
- **Tasks:**
  - Learn variables (let, const, var), data types (string, number, boolean)
  - Practice operators (arithmetic, comparison, logical)
  - Understand console.log and debugging
  - Write basic calculations and string manipulations
- **Mini Project:** Build a simple calculator that works in the console

#### Day 9: JavaScript Basics II
- **Tasks:**
  - Learn conditionals (if/else, switch, ternary operator)
  - Practice loops (for, while, forEach)
  - Understand functions (declaration, expression, arrow functions)
  - Work with arrays and array methods
- **Mini Project:** Create a program that filters and sorts an array of data

#### Day 10: Objects & Advanced Concepts
- **Tasks:**
  - Learn object creation and manipulation
  - Practice array methods (map, filter, reduce)
  - Understand scope and closures
  - Work with template literals
- **Mini Project:** Build a simple contact management system (console-based)

#### Day 11: DOM Manipulation
- **Tasks:**
  - Learn document.querySelector and querySelectorAll
  - Practice creating, modifying, and removing elements
  - Understand classList and style manipulation
  - Work with data attributes
- **Mini Project:** Build a dynamic to-do list app

#### Day 12: Events & User Interaction
- **Tasks:**
  - Learn event listeners (click, submit, input, keypress)
  - Practice event object and preventDefault
  - Understand event delegation
  - Work with form validation
- **Mini Project:** Create an interactive quiz application

#### Day 13: Async JavaScript Basics
- **Tasks:**
  - Learn setTimeout and setInterval
  - Practice callbacks
  - Understand localStorage and sessionStorage
  - Work with JSON (parse and stringify)
- **Mini Project:** Build a notes app with localStorage persistence

#### Day 14: Week 2 Project
- **Tasks:**
  - Build a complete interactive web application
  - Options: Expense tracker, Weather dashboard, Recipe finder
  - Must include: DOM manipulation, events, localStorage
  - Clean UI with CSS from Week 1
- **Deliverable:** Fully functional interactive web app

### Week 2 Best Resources
1. **JavaScript.info** (https://javascript.info/)
   - Modern JavaScript tutorial from basics to advanced
   - Clear explanations with runnable examples

2. **Eloquent JavaScript (Free Online Book)** (https://eloquentjavascript.net/)
   - Comprehensive JavaScript guide with exercises
   - Deep dive into programming concepts

3. **JavaScript30 by Wes Bos** (https://javascript30.com/)
   - 30 vanilla JavaScript projects in 30 days
   - No frameworks, just pure JavaScript practice

## Week 3: Advanced JavaScript & APIs

### Weekly Goal
Master async JavaScript, APIs, ES6+ features, and build real-world applications using external data.

### Daily Breakdown

#### Day 15: ES6+ Features
- **Tasks:**
  - Learn destructuring (arrays and objects)
  - Practice spread and rest operators
  - Understand modules (import/export)
  - Work with enhanced object literals
- **Mini Project:** Refactor previous projects using ES6+ features

#### Day 16: Promises & Fetch API
- **Tasks:**
  - Learn Promise creation and chaining
  - Practice .then() and .catch()
  - Understand fetch() for HTTP requests
  - Work with JSON responses
- **Mini Project:** Build a GitHub profile viewer using GitHub API

#### Day 17: Async/Await
- **Tasks:**
  - Learn async function syntax
  - Practice await keyword
  - Understand error handling with try/catch
  - Work with multiple async operations
- **Mini Project:** Create a movie search app using OMDB API

#### Day 18: Working with Real APIs
- **Tasks:**
  - Learn API authentication (API keys)
  - Practice different HTTP methods (GET, POST, PUT, DELETE)
  - Understand CORS and common API issues
  - Work with query parameters
- **Mini Project:** Build a weather app using OpenWeather API

#### Day 19: Advanced DOM & Performance
- **Tasks:**
  - Learn intersection observer
  - Practice debouncing and throttling
  - Understand lazy loading
  - Optimize JavaScript performance
- **Mini Project:** Create an infinite scroll image gallery

#### Day 20: Error Handling & Debugging
- **Tasks:**
  - Learn try/catch/finally
  - Practice browser DevTools debugging
  - Understand console methods (error, warn, table)
  - Work with breakpoints and debugging workflow
- **Mini Project:** Add comprehensive error handling to previous projects

#### Day 21: Week 3 Project
- **Tasks:**
  - Build a complete API-driven application
  - Options: News aggregator, Cryptocurrency tracker, Social media dashboard
  - Must include: Multiple API calls, async/await, error handling
  - Professional UI/UX design
- **Deliverable:** Production-ready web application

### Week 3 Best Resources
1. **RapidAPI Hub** (https://rapidapi.com/hub)
   - Thousands of APIs to practice with
   - Clear documentation and testing interface

2. **Async JavaScript Course - freeCodeCamp** (https://www.freecodecamp.org/news/javascript-async-await/)
   - Comprehensive async JavaScript tutorial
   - Real-world examples and patterns

3. **Chrome DevTools Documentation** (https://developer.chrome.com/docs/devtools/)
   - Official debugging and performance optimization guide
   - Essential for professional development

## Week 4: Modern Development & Final Project

### Weekly Goal
Learn Git, responsive design best practices, modern tooling, and build a complete portfolio-worthy project.

### Daily Breakdown

#### Day 22: Git & GitHub
- **Tasks:**
  - Learn Git basics (init, add, commit, status, log)
  - Practice branching and merging
  - Understand remote repositories (push, pull, clone)
  - Work with GitHub (README, gh-pages)
- **Mini Project:** Version control all previous projects and push to GitHub

#### Day 23: Responsive Design Mastery
- **Tasks:**
  - Learn mobile-first approach
  - Practice media queries and breakpoints
  - Understand responsive images (srcset, picture)
  - Work with viewport units (vh, vw)
- **Mini Project:** Make all previous projects fully responsive

#### Day 24: CSS Advanced & Animations
- **Tasks:**
  - Learn CSS transitions and transforms
  - Practice keyframe animations
  - Understand CSS variables (custom properties)
  - Work with modern CSS features
- **Mini Project:** Add smooth animations to portfolio projects

#### Day 25: Build Tools & NPM Basics
- **Tasks:**
  - Learn npm/package.json basics
  - Practice installing packages (live-server, prettier)
  - Understand build processes
  - Work with CSS preprocessors intro (optional)
- **Mini Project:** Set up professional development environment

#### Day 26: Web Performance & SEO
- **Tasks:**
  - Learn image optimization techniques
  - Practice minification and compression
  - Understand meta tags and semantic SEO
  - Work with Lighthouse audits
- **Mini Project:** Optimize all projects for performance (90+ Lighthouse score)

#### Day 27: Accessibility (a11y)
- **Tasks:**
  - Learn ARIA labels and roles
  - Practice keyboard navigation
  - Understand screen reader compatibility
  - Work with contrast ratios and semantic HTML
- **Mini Project:** Audit and improve accessibility of all projects

#### Day 28: Final Portfolio Project
- **Tasks:**
  - Build a comprehensive portfolio website showcasing all projects
  - Include: Hero section, Projects gallery, Skills section, Contact form
  - Must be: Responsive, Accessible, Performance-optimized
  - Deploy to GitHub Pages or Netlify
- **Deliverable:** Complete professional portfolio website

### Week 4 Best Resources
1. **Git & GitHub for Beginners - freeCodeCamp** (https://www.freecodecamp.org/news/git-and-github-for-beginners/)
   - Complete Git workflow tutorial
   - Essential for professional development

2. **Web.dev by Google** (https://web.dev/learn/)
   - Performance, accessibility, and best practices
   - Industry-standard guidelines

3. **A11y Project** (https://www.a11yproject.com/)
   - Comprehensive accessibility checklist and resources
   - Make your sites usable by everyone

## Daily Schedule Recommendation

**Morning (2-3 hours):**
- Watch tutorials and read documentation
- Take notes and understand concepts

**Afternoon (2-3 hours):**
- Complete hands-on practice tasks
- Build mini-projects

**Evening (1-2 hours):**
- Code review and debugging
- Participate in coding communities (Discord, Reddit, Twitter)

**Total: 5-8 hours per day**

## Additional Tips for Success

1. **Code Every Day:** Consistency beats intensity
2. **Build Projects:** Learning by doing is most effective
3. **Join Communities:**
   - freeCodeCamp forum
   - Dev.to
   - Reddit r/webdev
   - Discord coding servers

4. **Ask Questions:** Use Stack Overflow and ChatGPT when stuck
5. **Review & Refactor:** Revisit old code and improve it
6. **Stay Curious:** Explore beyond the curriculum
7. **Network:** Share your progress on Twitter/LinkedIn with #100DaysOfCode
